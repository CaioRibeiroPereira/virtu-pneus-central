# Sistema de atendimento — Pneus

CRM demonstrativo para acompanhamento do agente de atendimento de uma loja de pneus, com visão geral, clientes, funil de vendas e ficha do cliente.

Fonte: https://virtu-pneus-central.contato809171.chatgpt.site

Snapshot do código em 09/10/2026, commit de origem `3a19ff446880c9c2c64247aaf41c0d1614eeff37`.

## Desenvolvimento

Requer Node.js 22.13 ou superior e pnpm conforme package.json.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Para compilar: `pnpm build`. Consulte README.md para o ambiente Vinext/Cloudflare e migrações D1. A configuração de hospedagem original está preservada; subir no GitHub não migra os dados do ambiente publicado.
